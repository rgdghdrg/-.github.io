# Личная визитка — Ориентировщик / Бегун / Блогер

Современная «вау»-визитка с тёмной темой, анимациями и акцентом на спорт и истории.

## Как редактировать

Всё в одном файле:

```
js/config.js
```

Там меняешь:
- имя
- роль
- tagline
- описание
- увлечения (карточки)
- соцсети
- фото
- email

## Как запустить на GitHub Pages

1. Создай публичный репозиторий (лучше `твойник.github.io`)
2. Загрузи все файлы
3. Settings → Pages → Deploy from branch `main` → root
4. Готово

## Структура

```
├── index.html
├── css/style.css
├── js/
│   ├── config.js   ← редактируй здесь
│   └── main.js
├── assets/
│   └── avatar.svg  ← замени на своё фото (jpg/png)
└── README.md
```

После изменений на GitHub сайт обновится сам через 30–60 секунд.
